# Third-party components

Geenyan bundles the following libraries in `Resources/web/vendor/`, unmodified.
They are committed to this repository so the app renders entirely offline.

| Component | Version | License |
|-----------|---------|---------|
| [markdown-it](https://github.com/markdown-it/markdown-it) | 14.1.0 | MIT |
| [markdown-it-anchor](https://github.com/valeriangalliat/markdown-it-anchor) | 9.2.0 | Unlicense |
| [markdown-it-task-lists](https://github.com/revin/markdown-it-task-lists) | 2.1.1 | ISC |
| [highlight.js](https://github.com/highlightjs/highlight.js) | 11.10.0 | BSD-3-Clause |
| [Mermaid](https://github.com/mermaid-js/mermaid) | 11.4.1 | MIT |
| [KaTeX](https://github.com/KaTeX/KaTeX) | 0.16.11 | MIT |

Full license text for each is retained in the header of the corresponding
minified file, and in the upstream repositories linked above.
